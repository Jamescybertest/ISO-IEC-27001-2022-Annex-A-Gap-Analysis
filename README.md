# ISO-IEC-27001-2022-Annex-A-Gap-Analysis


Organization: MapleTrust Financial Services Inc. (Fictional)

Assessment: ISO/IEC 27001:2022 Annex A Gap Analysis

Assessment Type: Internal Information security Control Gap Assessment

Status: In Progress

## 1. Project Overview

This project demonstrates the application of ISO/IEC 27001:2022 to Conduct an ISO 27001 Annex A gap assessment for MapleTrust Financial Services, a fictional Canadian financial institution with 250 employees

The objective is to evaluate existing information security controls, identify gaps against applicable requirements, and recommend corrective actions based on associated security risks.

## 1. Assessment Scope

The assessment covers information security controls supporting MapleTrust's financial services operations, including: Customer information and financial records, Employee access to information systems, Information security policies and procedures, security awareness and training.

## 2. Assessment Criteria

Controls will be assessed against:

ISO/IEC 27001:2022 Annex A — reference information security controls

ISO/IEC 27002:2022 — implementation guidance

MapleTrust's internal information security policies and procedures

Applicable information security risk treatment requirements
