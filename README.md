# ISO-IEC-27001-2022-Annex-A-Gap-Analysis


Organization: MapleTrust Financial Services Inc. (Fictional)

Assessment: ISO/IEC 27001:2022 Annex A Gap Analysis

Assessment Type: Internal Information security Control Gap Assessment

Status: In Progress

## 1. Project Overview

This project demonstrates the application of ISO/IEC 27001:2022 Annex A information security controls to assess the current information security posture of MapleTrust Financial Services Inc., a fictional Canadian financial services organization.
The assessment focuses on evaluating control implementation, examining objective evidence, identifying control gaps, and developing corrective action recommendations to strengthen the organization's Information Security Management System (ISMS).
This project assesses information security controls, identifies weaknesses, and prioritizes improvements based on the risks they present to the organization.

## 1. Assessment Scope

The assessment covers information security controls supporting MapleTrust's financial services operations, including:

Customer information and financial records

Information systems supporting customer accounts and transactions

Employee access to information systems

Information security policies and procedures

Personnel security awareness and training

Relevant third party services

The assessment uses simulated organizational records and evidence.

## 2. Assessment Criteria

Controls will be assessed against:

ISO/IEC 27001:2022 Annex A — reference information security controls

ISO/IEC 27002:2022 — implementation guidance

MapleTrust's internal information security policies and procedures

Applicable information security risk treatment requirements
